# Claude Design brief: ISSUE11 onboarding (38 screens)
For Megan to paste into Claude Design, with the V4 Home file. Oct 8, 2026.
The flow and copy are **locked** (design/ONBOARDING-V3.md). This brief is only about the **look**. Don't change order or words; layout is free.

---

**Design the ISSUE11 onboarding in the exact V4 Home style.** 38 screens, but only **12 templates**: design each template once, then fill it with the copy below.

**Style (match V4 Home):**
- White page `#FFFFFF`, ink `#0d0d0d`, pink `#F65AAD`, blush `#FCD2DD`, cream `#F5EEE0`, cover red `#D40806`.
- Headlines: Archivo Black, UPPERCASE, very tight tracking (-0.05em), big (40–58px).
- Body: Archivo Narrow. Small labels: IBM Plex Mono 11px uppercase (keep this small font everywhere).
- Pills 44px tall, mono 11px labels; black filled for the main button.
- It must feel like flipping through a magazine, not filling in a form. Every screen should be screenshot-worthy.

**On every question screen:** thin progress bar at the top · small "ISSUE11" mono label · back arrow · one big headline · answers · one black button at the bottom (or auto-advance on single choice).

## Rules
- The paywall X must be clearly visible. Prices on the paywall are placeholders ("PRICE TBD").
- No fake numbers, logos or countdowns. Review slots say "Real beta review".
- Never write "your Issue is ready". It has *started*.
- Mobile 390×844. Text must stay readable (no tiny grey body text).
