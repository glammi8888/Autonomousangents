Magazine lab

Tap any text on any page to rewrite it. Templates with slots: a clean editorial set, then a zine set from Megan's inspo boards. Type below and swipe →

How it works in the app: each page is a fixed template with slots (name, headline, quote, photos). Text automatically shrinks to fit its box, photos crop around the face, and the date follows the real season. Pages are drawn at real magazine proportions (3:4), so the same layouts can be printed later. Try a long name or a long quote to see the auto-fit.
