## The 12 steps (about 30 to 40 minutes)

1. **Pick the right account.** Ads Manager (adsmanager.facebook.com) → account name at the top left → choose the **ISSUE11** ad account.
2. **Check the card.** Left menu ☰ → **Billing & payments** → **Payment methods**. You should see your card. If not: **Add payment method**.
3. **Check the $300 limit.** Billing & payments → **Payment settings** → **Account spending limit**. It should say $300. If not: **Set limit** → 300 → Save.
4. **Check the Pixel is firing.** Left menu → **Events Manager** → pick Pixel **2228324218041215** → **Overview**. PageView should show recent activity (green dot).
5. **Check the sign-up conversion.** Events Manager → **Custom conversions** → **Waitlist sign-up** should say **Active**. If it's missing: **Create custom conversion** → Pixel 2228324218041215 → All URL traffic → URL contains `thank-you` → Category **Lead** → Create. Then do one test sign-up on issue11.app and mark that row "test" in the Sheet.
6. **Start the campaign.** Ads Manager → **Campaigns** tab → green **+ Create** → **Leads** → Continue. Name: `ISSUE11 · Waitlist · US · Hook test Nov`. Special ad category: none. **Advantage+ campaign budget: OFF**.
7. **Set up ad set A.** Click the ad set → Name `Hook A · Manifestation doesn't work` → Conversion location **Website** → Pixel → **Waitlist sign-up** → Budget **$5 daily** → Start **today**, End **14 days later** (Dec 1).
8. **Audience and placements.** Same screen: Location **United States** → **Switch to original audience options** → Women, 18 to 40, no interests. Placements → **Manual placements** → untick everything except Instagram Feed, Explore, Explore home, Stories, Reels.
9. **Build ad A.** Click the ad → Identity: Page **Issue11** + Instagram **@issue11** → **Single image or video** → upload Reel A → paste the round 1 primary text and headline from the kit (section 3, Hook A) → CTA **Sign Up** → Website URL = the Hook A UTM link from the kit (section 2).
10. **Turn OFF every creative enhancement.** In the ad, find **Advantage+ creative** (or "Creative enhancements") → switch **every** option off (music, backgrounds, text variations, touch-ups). Our rule: nothing AI-made added by Meta. Also check **Website events: Pixel** is ticked.
11. **Make the A/B test for Hook B.** Before publishing: top bar → **A/B test** → variable **Creative** → in version B, swap in Reel B + Hook B round 1 text + Hook B UTM link. Same budget ($5), same dates, same audience.
12. **Publish and screenshot.** Press **Publish** (bottom right). Then send me a screenshot of the Campaigns tab. Status "In review" is normal and can take up to a day.
