# Pinterest board kit

Made by the 4h Pinterest agent (job 3, once), Nov 26, 2026. Builds on STRATEGY.md §6 ("Boards are keyword shelves, about 12, one per topic cluster") and the 4 content pillars Megan approved Nov 26 ("Ok smart"). Pinterest's own advice: board titles should be "clear and descriptive" to help search (how-to-make-pins page, in the issue11-pinterest skill playbook).

**Who does what:** this file is the kit. Creating or renaming boards on Pinterest is an account change, so Megan or the Manager does it, after Megan's go. The agent never touches the account.

**Rules:** the board name is the search phrase people type. The description says the keyword in the first line, then what she'll find, in her words (lowercase is fine on pins; board names use Title Case so they read like search results). One pillar per board. Every pin is saved first to the board that matches its keyword.
