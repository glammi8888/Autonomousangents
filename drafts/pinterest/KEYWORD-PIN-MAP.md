# Keyword → pin map (Megan, Nov 14: "a Pin for the same leadmagnet but in different keywords so we can rank as fast as possible")
One freebie, many pins. Each pin targets ONE search: that keyword goes first in the title, in the image text, in the description (natural, no stuffing) and in the board name. Every pin uses a fresh image or layout. All pins link to the same opt-in page.
Truth rule: a pin only uses a keyword the freebie really delivers (no "checklist" pin unless the checklist page exists).
Pacing: spread them out. A few new pins per day across all freebies, each one a fresh design, never a re-post of the same image. Metricool schedules them once Pinterest is connected. Megan reviews the first 2 weekly batches.
Volumes = Google US monthly searches (Mangools, Nov 14), a proxy for demand. Pinterest doesn't publish keyword volumes.
